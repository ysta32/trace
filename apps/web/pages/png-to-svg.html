When a PNG is ready for vector tracing

PNG is a good starting point for logos, icons, diagrams, and flat illustrations because it avoids the compression artifacts that can appear in JPEG files. An SVG describes shapes instead of storing a fixed grid of pixels. Those shapes stay crisp when resized, and their fills can be edited independently. Trace helps you move between these two representations without uploading your artwork.

Conversion is an interpretation of the pixels, not a recovery of the original design file. A tiny PNG cannot reveal a curve that was never captured clearly. Start with the largest clean source you have, ideally an original export rather than a screenshot. For artwork with soft shadows or photographic texture, consider whether keeping a raster image would better preserve its appearance.

How to convert a PNG to SVG

  1. Open your PNG in Trace. Use the app at the link above and choose your source image. Keep the original file so you can compare it with later versions.
  2. Choose a useful starting preset. Logo suits flat brand artwork, line art suits drawings, and pixel art is a better starting point for deliberately stepped edges. Photo poster is for a stylized interpretation of photographs.
  3. Review the palette. Begin with automatic palette and color count detection. Reduce the count if a simple design contains many nearly identical shades; increase it if meaningful color regions disappear.
  4. Compare and refine. Move the split-slider preview across important contours. Edit palette colors, then select individual shapes to recolor or delete stray pieces.
  5. Export SVG and inspect it. Open the result in its destination application and check it at both its intended size and a larger zoom.

Keep edges clean without losing character

Anti-aliasing adds intermediate pixels around an edge to make it look smooth. Those shades are usually not separate design colors. A smaller palette can help simplify the result, but too few colors may merge neighboring regions that need to remain distinct. Check holes inside letters, thin strokes, and narrow spaces before deciding that fewer colors is better.

A transparent PNG can still have faint edge pixels, and a white area may be actual artwork rather than empty background. Inspect the traced shapes before deleting anything. If you plan to place the SVG on several backgrounds, test it against both light and dark surfaces in your design application. This makes unwanted edge halos easier to notice.

Choose an export for the next step

SVG is a practical choice for web graphics and further vector editing. Trace also exports PDF, EPS, DXF, and PNG. PNG remains a raster output, so choose it when you need a finished bitmap rather than editable paths. For print or fabrication, confirm the receiving application's requirements and inspect dimensions and geometry after import.

For repeated work, batch conversion helps you process a set of assets. The CLI and npm package are available for developer workflows: install with npm i trace-vectorizer. Trace is open source under the MIT license, with code at GitHub. Keep a representative sample as a quality check before applying one set of choices to a whole collection.

Frequently asked questions

Does renaming a PNG to SVG convert it?

No. A filename change does not create vector paths. Tracing analyzes the visible regions and builds shapes that can be resized and edited.

Will the SVG always be smaller?

No. Complex textures can produce many shapes and a larger file. A simpler palette may help, but preserve the details your design needs.

Are my PNG images uploaded?

No. Trace processes images in your browser using WebAssembly. The image conversion takes place on your device, and using the converter is free.
